ALLMA point portrait · graphical asset attribution

The bounded upper-body point sample in avatar_mesh.js is derived from the
MakeHuman base mesh (base.obj, hm08), six baby and six child macro targets,
released under CC0 in September 2020. Only derived head, neck and shoulders
skin geometry is included, without eye helpers; no textures or
MakeHuman program code are included.

Source: https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj

ALLMA modifications: upper-body crop, bounded surface sampling, quantization,
sparse links, seeded morphological variation and expression deformations.
The particle revision adds one offline Catmull-Clark subdivision, locally
sculpted resting eyelids and adjusted child proportions. Only skin geometry
is included: no eye helper spheres. The visible image is drawn as neutral
white particles; the triangle surface is used only for hidden depth.
Generator: tools/build_avatar_mesh.py.

Age targets (same CC0 notice in each file):
https://github.com/makehumancommunity/makehuman/tree/master/makehuman/data/targets/macrodetails
african-female-baby.target, african-male-baby.target,
asian-female-baby.target, asian-male-baby.target,
caucasian-female-baby.target, caucasian-male-baby.target.
african-female-child.target, african-male-child.target,
asian-female-child.target, asian-male-child.target,
caucasian-female-child.target, caucasian-male-child.target.
The six targets in each age group are averaged; no ethnicity is inferred from
the user. The upstream baby and child anchors represent approximately one and
ten years. ALLMA blends them at 2/9 and 7/9 for an eight-year artistic appearance,
then reframes and sculpts the derived bust. Source hashes and blend weights are
stored in avatar_mesh.js. Age anchor reference (not bundled program code):
https://github.com/makehumancommunity/makehuman/blob/master/makehuman/apps/human.py
The presentation choices use subtle local deformations of the same child bust.
Distinct short, long and medium particle hairstyles are generated by ALLMA
and fitted to the sampled scalp. They are not upstream MakeHuman hair assets.

assets (CC0 1.0 Universal). This file concerns only the CC0 graphical asset.

C. The license for the bundled assets
-------------------------------------

The assets are defined as any data contributing to the graphical output of
MakeHuman. This includes:

* The base mesh and proxies
* Targets and modifiers
* Textures
* Clothes (any MHCLO-based asset)

D. Concerning the output from MakeHuman
---------------------------------------

It is the opinion of the MakeHuman project that no output from MakeHuman
contains any trace of program logic. That is, regardless of whether you use
the UI as such or if you call functions of MakeHuman via a script (such as 
via the blender importer), what you get is a combination of assets and your
own creative input. As the assets have been released under CC0, there is no
limitation on what you can do with this combined output.

To make it clear, the MakeHuman project makes no claim whatsoever over output
such as:

* Exports to files (FBX, OBJ, DAE, MHX2...)
* Exports via direct integration (import via MPFB)
* Graphical data generated via scripting or plugins
* Renderings
* Screenshots
* Saved model files

We regard these things as your data, which is yours to handle as you see
fit.

Note that what is discussed here are only assets bundled in the MakeHuman 
distribution. If you use a third part asset, such as one downloaded from the 
asset repositories, it is your own responsibility to make sure you abide by
its specific license. That license might be different from the one covering
the assets bundled by MakeHuman.
